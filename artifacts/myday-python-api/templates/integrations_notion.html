How it works

1
Connect your integration — add the Notion API token once; it applies to all sources.
2
Share pages — in Notion, connect each page or database to your integration (⋯ → Connect to).
3
Add sources — register each page or database here with a friendly name.
4
Import on demand — click "Import" to pull latest content into your Meeting Inbox. Duplicates are skipped.
5
Review before acting — nothing becomes a task automatically. You triage each note: create a task, keep as reference, or archive.
