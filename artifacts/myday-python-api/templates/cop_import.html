Before you run

  1. Export or save your CoP Org Plan as cop_org_plan_pc.csv (UTF-8).
  2. Upload the file to the project root in Replit — that is the top-level folder (same level as replit.md).
    {{ csv_path }}
  3. Make sure the CSV header row contains these columns (exact text matters):
    Effort   Topic   Topic Description   Sub topic/ Application   Type of K.O / Effort   Focus Market   Leader / Responsible   Notas   Jan … Dec
  4. Month cells should contain x (any case) when active, otherwise leave blank.
  5. Rows with an empty "Leader / Responsible" column are skipped automatically.

Run the import

Clicking the button below reads the CSV once and inserts every valid row into the database. You can run it multiple times — each run adds new rows (it does not deduplicate or replace existing ones). Clear the table in CoP Admin first if you need a clean slate.
