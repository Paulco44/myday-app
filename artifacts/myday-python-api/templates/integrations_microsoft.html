Confidencialidad

Solo metadatos viajan a la API de Claude por defecto: asunto, remitente y fecha de los emails, y título/hora de las reuniones. El cuerpo de los correos se guarda localmente en tu base de datos y el asistente solo lo lee si se lo pides explícitamente para un email concreto. El calendario se consulta en vivo (no se almacena).
